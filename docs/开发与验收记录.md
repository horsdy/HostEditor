- GUI 已启动；默认文件可读取，真实系统 hosts 未被测试写入。

## 待验收与限制

1. **受保护文件授权闭环**：开发签名版已实现 macOS 管理员认证触发的单次写入，限于当前文件并保留备份；可信签名版保留系统辅助服务。核心授权请求、路径版本校验与备份已自动检查，但系统认证提示、成功和取消流程尚未在本机端到端人工验收。本次未写入真实 `/etc/hosts`。
2. **系统兼容性**：构建目标为 macOS 13，但目前仅在本机启动；尚不能宣称所有 macOS 13 及以上版本均已验证。
3. **保存竞争条件**：采用文件锁、内容/身份/时间戳检查、目录描述符和原子替换，能够拒绝已检测到的外部改动。macOS 文件锁是协作式的；不配合锁的进程仍可能在最后检查与替换之间写入。现阶段不声称具备对任意非协作进程的严格比较并替换保证；需继续做压力测试并评估文件协调方案。
4. **大文件**：超过 1 MB 会提示；超过 32 MB 明确拒绝打开，不截断。主线程 100 ms 和冷启动 2 秒目标尚需专项测量。
5. **人工覆盖**：菜单栏左右键/Control+左键、最小化恢复、⌘F 选区预填及 Esc 收起、中文输入法、未保存操作组合、运行时系统外观变化、重启持久化、VoiceOver 及模拟磁盘满仍需完整验收。
6. **分发**：已生成 arm64 `.dmg` 安装包，但其中的 `.app` 仍是 ad hoc 开发签名，尚未完成 Developer ID 签名、公证或干净环境安装验证，不能作为正式对外分发版本。
7. **文本换行**：统一 LF、CRLF、CR、末尾换行状态及 UTF-8 BOM 均有保护；混合换行文件的未改动行保留原分隔符，新增或改动行采用文件默认换行风格。
